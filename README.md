# 🏨 Hotel Demand Analysis

**Hotel Booking Data Analysis | Python | Pandas | Excel | Power BI**

## 📌 Project Overview
This project analyzes hotel booking data to identify booking patterns, cancellation behavior, customer preferences, and revenue trends.

## 🎯 Project Objectives
- Analyze hotel booking demand.
- Understand booking cancellation patterns.
- Explore customer behavior.
- Identify revenue and pricing trends.
- Discover insights that can support better business decisions.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Excel
- Power BI

## 🧹 Data Cleaning
Python and Pandas were used to:
- Inspect the dataset.
- Handle missing values.
- Prepare the data for analysis.
- Export the cleaned dataset.

## 📊 Power BI Dashboard
An interactive dashboard was developed to explore hotel booking trends and business performance.

## 🔍 Key Analysis Areas
- Booking Demand
- Cancellation Rates
- Revenue and Pricing
- Average Stay Duration
- Booking Trends
